# What is Mod Companion?

Mod Companion (or Modcomp for short) is a standalone desktop app built to help with creating games and mods using [Valve's Source Engine](https://developer.valvesoftware.com/wiki/Source).

While Source Engine is proprietary, with only portions of its source code being publicly available, Mod Companion's code is fully open source and available for modification. 

This is achieved by not integrating into the engine directly. Mod Companion is a meta-program external to the engine that manipulates project files and interfaces with the game to run console commands.
